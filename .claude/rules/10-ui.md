# UI & Component Invariants

1. **Light-Only Standard**: Strictly Tailwind CSS v4 OKLCH light tokens. Never use `dark:` variants, `.dark` classes, or theme switchers.
2. **Semantic Tokens**: Ground values in DESIGN.md tokens (`bg-background`, `border-border`, `text-foreground`, `text-muted-foreground`, administrative accents).
3. **Restrained Iconography**: Lucide icons default to `strokeWidth={1.5}`. Never use decorative emojis or colored icon enclosure boxes.
4. **Data Dignity**: Display real operational metrics only. Never hard-code mock numbers, fake KPIs, or synthetic progress percentages.
5. **Single Control Point**: Never render duplicate search bars, parallel toolbars, or conflicting view toggles in the same view tree.
6. **Typography Floor**: Minimum text size is 12px (`text-xs`). Display and body use `Be Vietnam Pro` with proper Vietnamese diacritics.
7. **Accessibility**: Every interactive element requires an accessible name (`aria-label`, visible text), visible focus ring, and valid roles.
8. **Action Hierarchy**: Clear visual distinction: exactly one prominent primary CTA per flow; secondary actions use outline or ghost variants.
