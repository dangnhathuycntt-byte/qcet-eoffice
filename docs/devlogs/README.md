# Dev Logs — Nhật ký kỹ thuật

Nơi ghi lại quá trình debug, quyết định kỹ thuật nhỏ, và bài học rút ra.

Dùng template: [[templates/Template-Dev-Log]]

## Cách tạo
1. Tạo file mới trong thư mục này: `YYYY-MM-DD-mô-tả-ngắn.md`
2. Dùng Templater hoặc copy template
3. Liên kết tới ADR/Domain/Code liên quan

---

*Nhật ký sắp xếp theo ngày, mới nhất ở trên.*
